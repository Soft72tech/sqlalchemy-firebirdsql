# sqlalchemy-firebirdsql

Диалект SQLAlchemy для Firebird на базе pyfirebirdsql, с sync и async API.

[Возможности, ограничения и практические риски (на русском)](docs/capabilities.ru.md)

Документ описывает проверенный стек и различает нативные возможности сервера,
адаптации диалекта, неподдерживаемые функции и непроверенные сценарии.
